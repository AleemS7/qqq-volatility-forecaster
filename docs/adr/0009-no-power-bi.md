# 0009: No Power BI

- **Status:** Accepted, 2026-10-18
- **Context:** Power BI Desktop is a separate Windows install and needs a paid license to share. The gold tables already live in Databricks.
- **Decision:** Drop Power BI. Use a Databricks AI/BI dashboard defined in the bundle for internal views, and the public static page for sharing.
- **Consequences:** One fewer tool to install and maintain. Power BI does not appear on the resume from this project.
